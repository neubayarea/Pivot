# C11 全站界面重新设计：方案和样板（2026-10-26）

> 给 momomojun 确认用。对应 issue #288（接手 #32）。样板做在分支 `b/C-ui-overhaul` 的赛后页上，截图在
> `docs/screenshots/c11-prototype/`（1440 宽，before = 线上现在的样子，after = 样板，同一场比赛、同样的 AI 文字）。

## 一、现在哪里不对（检查结果）

**一眼像模板的地方**（frontend-design 列的几种"AI 味"，我们几乎全中）：
1. 到处是全大写、字母拉得很开的小标签："AFTER THE MATCH · …"、"WHY IT TURNED"、"VERIFIED ✓"。
2. 说明文字用中间点 `·` 串起来。
3. 整体是"报纸 / 比赛节目单"：细线分隔、方角、很粗的衬线大字（Alfa Slab One）。
4. 每一块都是同样粗黑边框的方盒子，看不出哪块最重要。
5. 链接后面都挂着 "→"。
6. 赛后页给每一块编了号（1–6），但这些内容不是先后步骤，编号没有意义。

**颜色对不上：** 两队的队服颜色在数据里是绿色（Harbour City `#1E6B45`）和深紫（Northgate Rovers `#4A1D57`），比分区的小色块也是这两个颜色；可是势头图、球场上的球员点却是写死的深蓝和红色。同一支队在一个页面里有两种颜色。

**我们最特别的东西没有突出：** AI 找到的转折点和"假如"，在页面上和定位球列表长得一样，"假如"还被放在第 5 块，离转折点很远。

**无障碍检查（web-design-guidelines，挑最要紧的）：**
- 键盘焦点框是金黄色，在浅色底上几乎看不见（对比度约 1.35，要求至少 3）。
- 势头图整体标成了"图片"，图上的转折点按钮读屏软件读不到。
- 射门图的点不能用回车键打开。
- 顶部比分区固定在上面，但跳转时内容会被它挡住。
- 主按钮、切换按钮没有鼠标悬停效果。
- 深色模式下，红底白字、浅蓝底白字的对比度不够。
- 事件列表整块设成了"有新内容就朗读"，回放时读屏软件会一直念。
- 数字的分钟有的用 `'`，有的用 `′`。

完整清单在 `side-session-notes` 里（共 25 条，按影响排序），第 3 个 PR 会逐条处理。

## 二、新方案："队服对撞"

### 一句话
页面本身保持安静的灰白；**两队的真实队服颜色**负责所有数据；**一种黄色只留给 AI**：转折点、核对过的数字。看到黄色，就是 AI 找到并核对过的东西。

### 颜色（6 个）
| 名字 | 色值 | 用在哪 |
|---|---|---|
| 看台灰 Stand | `#ECEEF1` | 页面底色，偏冷的混凝土灰（不是米黄） |
| 白 Sheet | `#FFFFFF` | 内容面板 |
| 墨 Ink | `#121418` | 文字、选中状态 |
| 主队队服 | 来自数据，现在是 `#1E6B45` 绿 | 比分区左半、势头图上方、主队球员点 |
| 客队队服 | 来自数据，现在是 `#4A1D57` 深紫 | 比分区右半、势头图下方、客队球员点 |
| 转折点黄 Pivot yellow | `#FFCC1F` | **只给 AI**：转折点的圆标、选中的转折点、核对过的数字下划线 |

另外：次要文字 `#565D6B`（在灰底上对比度 6.0），键盘焦点框改成蓝色 `#1F5FFF`（在白底上对比度 5.4）。深色模式（夜场）同一套，队服颜色自动调亮。

### 字体（都来自 Google Fonts，开源许可）
- **Big Shoulders Display**（窄体、粗）：只用在数字和少数大标题上，比如比分、分钟、转折点编号、页面大标题、"What if…"。它本来是为城市指示牌设计的，像球场记分牌。
- **Hanken Grotesk**：其他所有要读的文字，正文 16px，行高 1.55。
- **Noto Sans SC**：中文。中文大标题用 Noto 700，不混用窄体数字。
- 字号阶梯：12 / 14 / 16 / 18 / 24 / 36 / 48 / 72。
- **不再用全大写。** 标签都用正常的句子写法，靠颜色、粗细、位置分主次。

### 圆角和层次
- 面板 14px 圆角，按钮 8px，小标签全圆。大小不同，表示它们的地位不同。
- 面板不加黑边框，白色面板放在灰底上就能分开。
- **全页只有一个面板浮起来（带阴影和黄色顶边）：打开的那个转折点。**

- 全站内容左对齐，最宽 1280px，左右留 32px。
- 势头图沿用英超官网的样子（主队在上、客队在下、进球标在中线上），评委会觉得熟悉。

### 原则
1. **黄色只属于 AI。** 别的地方都不用黄色，这样黄色一出现就有意义。
2. **颜色就是数据。** 队服颜色只用来表示"这是哪一队"，页面装饰不用队色。
3. **一页只有一个主角。** 赛后页的主角是"势头图 + 转折点"，其他部分安静。
4. **不用装饰性的标签。** 不加全大写小标签、不编没意义的号、不挂 "→"、少用中间点。
5. **先熟悉，再特别。** 比分区、标签页、势头图都照英超官网的习惯；特别的只有转折点和"假如"。

### 让人记住的那一个东西
**势头图上的黄色转折点。** 点一个，图上对应的那段时间亮起一条黄色窗口，下面展开那一刻"为什么会转折"、当时的球场，以及"假如那一刻换个决定会怎样"。AI 找到的、核对过的、可以重新模拟的，全在这一处。

### 对照要求自查后改了什么
- 一开始想用**深草绿做整个顶部**，配荧光黄绿。后来发现 Harbour City 的队服就是绿色，放在绿底上会看不见；荧光绿配深色底也正好是"AI 味"清单里的一种。所以改成**两队队服各占一半**，颜色跟着比赛走，换一场比赛就换一种颜色。
- 一开始想沿用金黄色做所有按钮和选中状态。改成**金黄色只给 AI**，按钮用墨色，选中的标签用墨色下划线，否则黄色到处都是，就不特别了。
- 去掉了赛后页 1–6 的编号，因为这些内容不是先后步骤。

## 三、样板里已经做了的（赛后页）
- 新的颜色、字体、圆角（全站一起生效，因为沿用了原来的颜色名字）。
- 势头图和球场改用两队真实的队服颜色。
- 比分区改成两队颜色对撞，比分放在深色记分牌里。
- 标签页改成白色、左对齐。
- 赛后页：势头图做主角，转折点挂在图下面，"假如"放进打开的转折点里。
- **没有指定转折点时，默认打开第一个**（这样一进页面就看到 AI 的解释）。以前要先点一下。

- 去掉了全大写、"→"、编号；"Momentum → Harbour City" 改成 "Swung to Harbour City / 势头转向 / El impulso pasa a"。
