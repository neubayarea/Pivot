# 合体测试清单（T03 本机 · T04 线上）

按 2 分钟演示的路线排：打开首页（默认比赛）→ 选比赛 → 回放 → 势头曲线 → 转折点卡片 → 「假如」实验室 → 旧链接。
每一条写了怎么操作、应该看到什么，以及在本机（T03）和线上（T04）各怎么做。最后一节是每次试走的记录。

- 线上：https://pivot.in-stacks.com （甲骨文服务器 2 核，`pivot_api.single` 一个进程，AI 用 Azure Foundry，AI 结果存 Cosmos DB）
- 本机：http://127.0.0.1:8000 （同一个程序，假流水线，不连 Azure）
- 比赛：网站只放普通模拟比赛（线上 20 场，本机按 `PIVOT_SIM_MATCHES`），没有特意安排剧情的演示比赛（Ax55）。**默认比赛**就是顶栏比赛列表里的第一场（种子列表的第一个，现在是种子 101，`M-seed-101`）。
- 这份清单不写死某一场的分钟和比分：模拟规则一改（模拟版本号变了），比赛和转折点都会重新生成。下面说「第一个转折点」，就是转折点列表里最上面那条。

## 0. 准备

### 本机（T03）

需要 [uv](https://docs.astral.sh/uv/) 和 pnpm。在仓库根目录：

```bash
uv sync && pnpm install && pnpm --filter web build
```

```bash
PIVOT_PIPELINE=fake PIVOT_SIM_MATCHES=1 PIVOT_WHATIF_WARM=0 PIVOT_RESULTS_BACKEND=files PIVOT_DATA_DIR=.pivot-data uv run python -m pivot_api.single
```

- `PIVOT_PIPELINE=fake`：不调模型，解释全是模板文字（这是对的，不算失败）。不要在本机填真实的 Azure 设置。
- `PIVOT_SIM_MATCHES=1`：只生成一场模拟比赛（种子 101，也就是默认比赛），几秒钟就好；不设就是 20 场。
- `PIVOT_WHATIF_WARM=0`：启动时不预先算「假如」，省 CPU。
- `.pivot-data/` 已在 `.gitignore` 里，别提交（见 [比赛数据放在哪](../match-data.md)）。
- 换端口：前面加 `PORT=8011`。

看到 `Uvicorn running on http://127.0.0.1:8000` 后检查：

```bash
curl -s http://127.0.0.1:8000/healthz
```

```bash
curl -s http://127.0.0.1:8000/api/sims
```

应该是 `{"status":"ok"}`，以及 `ready` 等于 `total`。

### 线上（T04）

```bash
curl -s https://pivot.in-stacks.com/healthz
```

```bash
curl -s https://pivot.in-stacks.com/api/sims
```

`ready` 应等于 `total`（20），`failed` 为 0。改了模拟规则后第一次启动要 1 分半钟左右才全部算好，期间顶栏写「正在生成比赛… x/20」。

- 服务器只有 2 核：没人问过的「假如」要几分钟，还要排队。一次只点一个，不要连续点很多个新问题。
- 浏览器以前打开过网站的话，会记住上次选的比赛（`localStorage` 的 `pivot.match`），所以首页不一定是默认比赛。录演示前用无痕窗口。

## 1. 首页

| # | 怎么操作 | 应该看到 | 本机 / 线上 |
|---|---|---|---|
| 1.1 | 打开首页（不带 `?match=`，无痕窗口） | 打开的是默认比赛（顶栏比赛列表的第一场）。先出现灰色卡片轮廓，1–3 秒内变成看板：顶栏（比分、时钟、比赛下拉框、分析师/球迷、关注球队/球员、EN/中文/ES、溯源），下面是势头曲线、转折点列表、球场动态、比赛数据。没有红色的「连接断开」横条 | 两边一样 |
| 1.2 | 打开浏览器开发者工具的 Console | 没有红色报错 | 两边一样 |

## 2. 选比赛

| # | 怎么操作 | 应该看到 | 本机 / 线上 |
|---|---|---|---|
| 2.1 | 点顶栏的比赛下拉框 | 只有模拟比赛，按种子从小到大排（「种子 101」「种子 212」…），当前比赛是第一项；没有「演示」，也没有手写样例 | 本机：种子 101；线上：20 场 |
| 2.2 | 选另一场 | 地址变成 `?match=M-seed-…`，比分、势头曲线、转折点、数据都换成这一场的 | 两边一样 |
| 2.3 | 再切回第一场 | 恢复成默认比赛 | 两边一样 |

## 3. 回放、进度条、球场跑动

| # | 怎么操作 | 应该看到 | 本机 / 线上 |
|---|---|---|---|
| 3.1 | 点「开始演示」 | 出现回放条（暂停键、进度条、1×/5×/20×/60×、从头播放）。比分回到 0–0，状态「直播中」，转折点列表变成「还没有转折点」，势头曲线从 0′ 开始画 | 两边一样 |
| 3.2 | 球场动态 | 22 个号码圆点和球在动（每秒一帧，圆点平滑移动），右上角写「HBC 向右进攻」 | 两边一样 |
| 3.3 | 点 60×，在进度条中间点一下 | 时钟跳到那里继续走；比赛数据右上角的时间范围跟着变 | 两边一样 |
| 3.4 | 点暂停，再点播放 | 状态变成「已暂停」，时钟停住；再点继续 | 两边一样 |

## 4. 势头曲线

| # | 怎么操作 | 应该看到 | 本机 / 线上 |
|---|---|---|---|
| 4.1 | 回放过第一个转折点的分钟 | 曲线往一方明显偏；那一分钟出现红色竖线和分钟标签；转折点卡片在几分钟后弹出（要等变化后 5 分钟确认） | 两边一样 |
| 4.2 | 回放到终场（或不开回放直接看全场） | 半场处有灰线；每个转折点一条红线，数目和右侧转折点列表一致 | 两边一样 |

## 5. 转折点卡片和详情页

| # | 怎么操作 | 应该看到 | 本机 / 线上 |
|---|---|---|---|
| 5.1 | 看右侧「转折点」列表 | 每个转折点：分钟、标题、严重程度（红点）、「已核实 ✓」、「势头 → 球队」 | 本机标题是模板文字（例如「一张牌改变比赛」），这是正常的；线上是 AI 写的 |
| 5.2 | 点第一个转折点 | 进入 `/pivot/<比赛>:p<分钟>`：大号分钟、标题、「已核实 · 数据 N 项 · 证据 N 条」、「势头 → 某队」；右边「为什么会转折」几句解释，每句后面有 `#800` 这样的证据号；底部「判定 ✓ · 撰写 ✓ · 核对 ✓」 | 两边一样（本机文字是模板） |
| 5.3 | 点一个证据号 | 左边小球场标出那个事件的位置（射门有箭头），下面的时间轴跳到那一秒，说明行写「#证据号 · 分钟 · 事件 · 球员」 | 两边一样 |
| 5.4 | 在详情页点 EN、中文、ES | 界面文字和解释都换成对应语言，标题、句子、证据号都还在 | 线上第一次切某种语言可能要几秒（现写） |
| 5.5 | 切换「分析师 / 球迷」 | 解释换成另一种写法（球迷版更口语） | 线上第一次切某个组合可能要几秒（现写），之后瞬间出 |
| 5.6 | 看英文、西语下的顶栏 | 比分旁两队简称和比分都看得清 | **线上 1024–1115px 宽时队名被挤成一个字母（#195）** |
| 5.7 | 核对解释里的人名、分钟 | 解释里提到的球员、分钟和证据事件一致 | 两边一样 |
| 5.8 | 点顶栏「溯源」 | AI 每一步的记录（判定、撰写、核对），每个转折点一组 | 本机是假流水线的记录 |

## 6. 「假如」实验室

| # | 怎么操作 | 应该看到 | 本机 / 线上 |
|---|---|---|---|
| 6.1 | 在第一个转折点的详情页点「假如…」 | 进入 `/whatif/<转折点>`：左边是这个时刻能改的芯片（例如取消某次换人、判某个进球无效、撤销红牌、从这一分钟起压得更高），不适用的芯片是灰的并写明原因；下面「确认改动」和 200/500/1,000 场 | 两边一样 |
| 6.2 | 选第一个能点的芯片、200 场，点「开始重踢」 | 出现「重踢中 · 已踢完 x / 400 场」进度条。本机约 30 秒完成；线上没人问过的要几分钟，问过的标「之前算过 · 直接出结果」 | 线上只点一个 |
| 6.3 | 看结果 | 一句话结论 +「差别明显 / 差别不大」；「原来的样子」和「改了以后」两条胜平负条；95% 误差范围图；「差别从哪来」几句解释；「换一个试试」 | 同一个问题本机和线上数字应**完全一样**（同种子可复现） |
| 6.4 | 点「换一个试试」 | 回到芯片列表，可以再选 | 线上别再点新的 |

## 7. 旧链接

| # | 怎么操作 | 应该看到 | 本机 / 线上 |
|---|---|---|---|
| 7.1 | 打开 `/?match=M-seed-29`（以前的演示比赛，现在没有了） | 打开默认比赛，顶栏下面一行提示「已经没有名为“M-seed-29”的比赛了，现在显示的是第一场比赛。」，点「知道了」消失 | 两边一样 |
| 7.2 | 打开 `/overlay` | 跳到 `/overlay/<上次选的比赛>`，没选过就是默认比赛 | 两边一样 |

可以用接口快速看默认比赛的转折点（线上把地址换成 https://pivot.in-stacks.com）：

```bash
curl -s "http://127.0.0.1:8000/api/matches" | python3 -c "import json,sys; print(json.load(sys.stdin)[0]['match_id'])"
```

```bash
curl -s "http://127.0.0.1:8000/api/matches/M-seed-101/pivots?lang=zh" | python3 -c "import json,sys; [print(p['pivot_id'], p['status'], (p.get('narrative') or {}).get('source'), (p.get('narrative') or {}).get('headline')) for p in json.load(sys.stdin)]"
```

第一条打印默认比赛（列表第一场）；第二条把 `M-seed-101` 换成它。
