# ADR-0015：阵容战术、生涯与场外因素进入模拟，并且必须可追溯

- 状态：已采纳（待开工会确认）
- 日期：2026-10-23
- 决策者：B（模拟）
- 相关：ADR-0005、ADR-0014

## 背景

真实比赛里，很多转折点的原因不在场上：教练换了阵型、球员面对旧主、和老队友或老教练重逢、杯赛决赛和联赛的心态不同、赛前一晚的场外新闻。足球游戏和数据应用也把这些做成了数据：

- 能力值分成进攻、技巧、移动、力量、心理、防守、门将七组，共三十多项；
- 管理类游戏还有不显示在界面上的性格值，例如稳定性、大赛表现、抗压、职业素养；
- 阵容单写明阵型、每个首发的位置、队长和定位球主罚人；战术写明防线高度、压迫、宽度、节奏和传球方式。

如果我们的数据只有 8 项能力值、没有阵容单和场外信息，解释就只能停在场上统计；“教练把 4-3-3 换成 5-4-1”“前锋第一次回到旧主场”这类球迷最关心的故事讲不出来。

## 决策

1. **能力值**：34 项可见能力值，分七组（进攻、技巧、移动、力量、心理、防守、门将），再加 6 项汇总分（速度、射门、传球、盘带、防守、身体），由明细按权重算出，是游戏卡面的近似。另有 11 项隐藏性格值，以及身高、体重、年龄、惯用脚、逆足、花式、攻防积极性和球员特长标签。
2. **阵容和战术**：`TeamSheet` 写明阵型、首发和他们在阵型里的基准位置、替补、队长、点球 / 任意球 / 左右角球主罚人；`TeamTactics` 写明防线高度、压迫、宽度、节奏、传球方式、进攻侧重、是否打反击、造越位、拖延时间，以及针对个人的指令（插上、内切、盯人等）。开场、阵型调整和换人事件都带上新的阵容单和战术。
3. **生涯与关系**：每名球员和教练有生涯经历（效力过的俱乐部、出场、进球、怎么离开、离开时关系好不好），人与人之间有关系（老队友、老教练、导师、对头等）。
4. **比赛背景**：赛事（联赛、国内杯、洲际俱乐部赛事、国家队大赛、友谊赛）、阶段（小组赛到决赛）、重要程度、主场或中立场、德比、争冠或保级、天气；每名球员的赛前状态（体能、比赛节奏、士气、最近五场评分、休息天数、带伤、再吃一张黄牌会停赛）；以及场外新闻（夜店、迟归、家事、合同纠纷、转会传闻、被公开批评、训练冲突等）。
5. **影响必须小，而且必须可追溯**。模拟器在开球时把背景换算成一组 `ContextEffect`，每条写明对谁、因为什么（指向新闻、生涯或关系的编号）、影响哪一项（沉着、积极性、专注、体能、侵略性、默契、吃牌风险、失误率）、影响多少。单条影响的绝对值不超过 0.15。AI 引用场外因素时，句子必须带 `context_ids`，核查员检查它们真实存在，否则判为 `context_invalid`。
6. **全部虚构**。球员、教练、俱乐部、赛事、新闻全部是虚构的，不使用真实球员的名字或真实事件，不使用真实赛事的品牌名（例如写“洲际俱乐部杯”，不写真实赛事名）。场外新闻只描述行为，不做道德评判，也不涉及违法、伤病隐私和家人细节。

## 后果

- **正面**：解释可以讲出场外的故事，并且每条都能点开看到依据；推演可以改阵容和战术；关注球员模式有了个人背景。
- **负面**：数据量和生成工作量明显增加，需要一个“虚构世界生成器”来造俱乐部、球员、生涯和关系（B13）。
- **风险**：场外因素的影响是我们自己定的规则，不是统计规律，可能被质疑。缓解办法：影响设得很小，并在界面和 README 里说明这是“模拟假设”；评测时看场外因素有没有让结果明显偏离标定范围。
