# 定位球站位（Ax44，#245）

角球和任意球开出前，球员该站在哪里：数字从哪来、模拟器怎么照着站、和英超比差多少。

代码：`packages/pivot_core/src/pivot_core/sim/setpieces.py`。真实数据：`scripts/setpiece_reference.py` → `eval/realism/reference.json` 里的 `set_pieces_pl1516`。对照：`uv run scripts/realism_scorecard.py --set-pieces`。

## 站位影响比赛

角球和任意球前，球员在停球的这几十秒里按自己的速度走到定位球位置（模拟器的跑位目标换成定位球站位）。对方没退到 9.15 米外，裁判就不让开球。开球后的传中、争顶、解围、射门都按这时真实的站位算，所以比赛过程和结果都会变。比赛页默认打开的 M-seed-29 也变了：`uv run scripts/make_demo.py --seed 29` 重新生成 `eval/fixtures/demo-1021.json`。改之前的那场比赛冻结在 `eval/frozen/`，只给测试用（见那里的 README）。

- 站位用模拟器自己的另一条随机数（种子加 3）：同一个种子每次踢出同一场比赛。
- 开球后，离球 5 米以内的人、接球人、持球人照常踢；其他人在球还在禁区附近、防守方还没拿到球时守住位置（最多 8 秒），然后回到平时的跑位。
- 角球传中不再瞄准站在门将身前、离门线 4 米以内的人（`Params.corner_line_pen`）。这样的球真实比赛里多半被门将没收；不加这一条，门将扑救角球的次数会翻倍，头球射门会少三分之一。

## 真实数据：英超 2015/16 的定位球站位

来源：StatsBomb 开放数据（[github.com/statsbomb/open-data](https://github.com/statsbomb/open-data)，competition 2 / season 27，380 场）。这个赛季没有全程追踪数据，但每一脚射门都带「定格画面」（freeze frame）：射门那一刻镜头里所有球员的位置。

- **角球**：角球后 6 秒内、同一次控球里、由开角球一方射门，共 1,126 脚。画面在开球后一两秒，禁区还是满的。
- **前场任意球传中**：同样的办法，共 380 脚。
- **直接任意球**：任意球射门本身就是开球那一刻，共 401 脚，人墙、门将、禁区都能直接数。

怎么数的：英超数据的坐标是 120×80 码，换成 105×68 米。「人墙」是离球 1.5–12 米、在球到球门中心连线两边 25 度以内的防守球员（和比赛页 `setpieces.ts` 的判定一样）；「人墙人数」只数最靠近球的那一排（最近那人往后 1.5 米以内）。门柱「有人」指离门线 2 米、离门柱 2.5 米以内有防守球员。

定格画面只有镜头拍到的人（平均 17 人），留在后场的人几乎拍不到。所以「进攻方留几个人防反击」「防守方留几个人在前场」这两项没有可靠的英超数字，按下面的公开资料定。

## 公开资料

- 规则：任意球时对方球员离球至少 9.15 米；三人以上排人墙时，进攻方球员要离人墙至少 1 米（[Law 13](https://www.thefa.com/football-rules-governance/lawsandrules/laws/football-11-11/law-13---free-kicks)）。角球时对方离角球弧至少 9.15 米（[Law 17](https://www.thefa.com/football-rules-governance/lawsandrules/laws/football-11-11/law-17---the-corner-kick)）。
- 英超球队怎么防角球（[Premier League, Adrian Clarke, 2022/23](https://premierleague.com/news/2982222)）：大多数球队区域和人盯人混用，只放一两个区域球员的很少。阿森纳在小禁区放 4 名区域球员（近门柱 2 人、中间 1 人、远门柱 1 人），其余人盯人。利物浦小禁区 6 名区域球员，前面 2 人，弧顶和防短角球 2 人。西汉姆 5 名区域球员、3 名盯人、2 名机动，11 人全回。曼城 5 人围着门将、4 人一对一、1 人在弧顶。
- 2022 世界杯（[FIFA Training Centre](https://www.fifatrainingcentre.com/en/game/game-analysis/set-plays/defending-corners-zonal-or-player-to-player.php)）：32 队里 26 队 10 名场上球员全回，6 队留 1 人在前场；只有 5 队在门柱放人。4 名以上区域球员算区域防守，欧洲球队 62% 是区域防守。人盯人的球队通常 5–6 名盯人、2–3 名区域、1–2 名在弧顶。
- 进攻方跑位（[guidetofootball.com](https://guidetofootball.com/tactics/corner-routines/)、[sportsessionplanner](https://www.sportsessionplanner.com/s/6MBjb)）：近门柱、远门柱、中路、点球点各一个跑位点，有人站在门将前面挡他；弧顶 1–2 人抢第二点；后场留 2–3 人防反击。
- 学术研究（[Pulling et al., 2013, 英超 50 场角球](https://www.ingentaconnect.com/content/uwic/ujpa/2013/00000013/00000001/art00012)）：当年 90% 的角球用一对一盯人。现在混合防守更多，所以模拟器默认用混合。

## 模拟器的规则

坐标都按罚球一方的方向，「近侧」指角球那一侧的门柱。

| 情况 | 谁 | 站哪里 | 依据 |
|---|---|---|---|
| 角球 | 罚球人 | 角球弧（模拟器本来就是） | 规则 |
| | 进攻方禁区内 | `players_forward_on_corners`（默认 5）上下浮动 1 人，4–7 人。依次站：门将前 1.6 米、近门柱前（5.5 米）、远门柱（6 米）、点球点、中路、远侧后插上、近侧后插上。中锋、中卫先进，再是前腰和边锋 | 英超 5.3 人；阿森纳、利物浦的跑位 |
| | 进攻方其他人 | 弧顶 1 人（四分之一的时候 2 人）；五分之一的时候 1 人在角旗边接短角球（离角旗约 9 米）；后场留 2–3 人（边后卫、后腰） | 英超弧顶 0.8 人；教练资料后场留 2–3 人 |
| | 防守方前场 | `players_back_on_corners`（默认 1，可 0–3）人留在中线附近，前锋优先 | 世界杯 26/32 队全回，6 队留 1 人 |
| | 防守方禁区 | 按 `corner_defence`：**区域** 6 个区域 + 盯 2 名威胁最大的人；**混合**（默认）4 个区域（近门柱两人、中间、远门柱）+ 其余人盯人；**人盯人** 2 个区域 + 每名禁区内的进攻球员一个盯人。区域位置依次是：近门柱前区、近门柱、小禁区线中间、远侧、点球点两侧……盯人的站在对手和球门之间 1 米，对手动他也动。剩下的人站弧顶，有短角球时派一人出去 | 阿森纳、利物浦、西汉姆、世界杯的配置 |
| | 门柱 | 36% 的角球近门柱放一人，31% 远门柱放一人（占区域名额） | 英超定格画面 36% / 31% |
| | 门将 | 门线前 1–1.5 米，略偏远侧 | 英超 1.3 米 |
| 直接任意球（32 米内、在球门正面） | 人墙 | 离球 9.15–9.5 米，最外一人在球到近门柱外侧的连线上，其余人肩并肩往球门中间排。人数按距离：20 米内 6 人，20–25 米 5 人，25–30 米 4 人，更远 2 人，上下浮动 1 人；角度偏（离中线超过 12 米）少 1 人。中卫尽量不进人墙 | 英超 6.5 / 5.0 / 3.8 / 2.0 人；规则 9.15 米 |
| | 门将 | 门线前 1–2 米，站人墙挡不到的那一边 | 英超 1.3–1.5 米 |
| | 进攻方 | 4 人（浮动 1）在防线上；离球 12 米内最近的队友留在原地当短传点；没有这样的人时一半的时候有人站在球边；三人以上人墙时一半的时候有人站在人墙边 1.1 米；弧顶 1 人；后场 2 人 | 英超禁区进攻 4–5 人；规则 1 米 |
| | 防守方其他人 | 防线在点球点附近（离门线 = 任意球距离 − 11 米，9–15.5 米之间）：每人贴一名进攻球员，多出来的守门前区域；40% 的时候留一名前锋在前场 | 英超禁区防守 9–10 人（25 米内） |
| 前场任意球传中（进攻三区、射不了门） | 人墙 1–2 人；防线在离门线 9–16.5 米（任意球越近越深）；进攻 5 人上防线，其余同上 | 英超任意球传中：禁区进攻 5.1、防守 7.8 人 |
| 其他任意球（中场、后场） | 对方离球不够 9.15 米的退到 9.15 米外，其他人照常跑位 | 规则 |

球员按平时的走位速度（不冲刺）走到位置。站在禁区里的人每秒有零点几米的小动作；每次定位球的站位各差半米左右。站位每秒按球员当时的位置重新分配一次（同一次定位球用同一组随机数），中途有人被换下或罚下也能接上。对方有人在 9.15 米以内时裁判不让开球（最多等 60 秒）；开球那一秒防守方站住不动。

还差的地方：

- 小禁区里防守人数开球时偏多（4.5 对 3.1）。英超的数字是射门那一刻，防守球员已经往外迎球了；模拟到射门时是 2.2。
- 25 米外的任意球，禁区里的防守偏多（25–30 米 8.5 对 6.8，30 米外 7.4 对 5.4）：真实比赛远距离任意球有人站在禁区外，模拟器的防线都在禁区里。
- 人墙比真实的远半米：规则要求 9.15 米，真实球员常偷偷往前挪。
