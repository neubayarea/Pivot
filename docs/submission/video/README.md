## 先看规则要什么

**官方规则 4.4**
- 视频必须短于 2 分钟，要拍到软件真的在运行。
- 链接要公开，放在 YouTube 或 Vimeo 等网站上。
- 不能用没有授权的音乐，也不能出现别人的商标。

**规则 4.9**：材料要用英文。

**规则 4.1**：一条五个阶段的流水线。
1. 接收（Ingest）；
2. 解读（Interpret）；
3. 解释（Explain）；
4. 呈现（Render）；
5. 个性化（Personalize）。

第 5 步原文要求同一份分析给数据控分析师和普通球迷"两种真正不同的体验"，还要有主队、关注球员和多语言。

**评分五项，各占 20%**
- 技术实现；
- 智能体设计与创新；
- 现实影响；
- 体验与展示："视频是否清楚讲出项目价值"；
- 是否符合赛道。

## 思路

1. **按五个阶段讲。** 配音里依次出现：
   - ingests（接收）；
   - renders it beside the action（呈现）；
   - turns the events into momentum（解读）；
   - Judge / Explainer / Verifier（解释）；
   - personalises（个性化）。

   评委对照赛道描述，一听就能对上。
2. **球迷版和分析师版的区别，放在镜头里切给评委看。**
   - 开头先放赛中球迷版：球场、"现在谁占上风"、比赛大事；
   - 然后当场点 **Analyst**，同一分钟变成最近十分钟 xG、场面倾斜、PPDA、控球加趋势线，球场上再开压迫区域和传球线路；
   - "假如"标签也是同样的切法，先球迷版，再分析师版。

   这样"两种真正不同的体验"不用靠嘴说。
3. **把"AI 写的每个数字都核对过"拍出来。** 鼠标停在 "4 to 14" 上，提示框显示这个数字的来源："7′–11′ 是 4 次，12′–16′ 是 14 次"。
4. **个性化连着拍**：选主队，故事换成站在你这边说；切中文和西语；关注一名球员。
5. **假如**：
   - 球迷版是一句话加两个大数字（44% → 20%）；
   - 分析师版是 +16 分、95% 区间、"区间不重叠"。
6. **分析师的深度分析快速扫一遍**：比赛分段、比分状态、射门质量、进攻通道、风格雷达，说明分析师版有专业深度。
7. **结尾卡**：
   - 列出用到的微软技术：Azure AI Foundry、Microsoft Agent Framework、Cosmos DB、Blob Storage；
   - 网址和仓库地址；
   - 写明"全部是虚构数据"。

每一段左下角有一个小标签（比如 "Live · Fan view"），评委随时知道自己在看哪一部分。

**这一版没讲到、或讲得轻的亮点**（时间只有 2 分钟）：
- **AI 日志的改稿过程**：Verifier 把写错的稿子退回，Explainer 重写，三次不过就用规则模板。片子里只在结尾卡写了一句。v3 加了 AI 日志页这一段，但没有用于提交。
- **我们自己写的模拟器**：22 名球员每秒都有位置，可以在任意一分钟存档再踢下去。片子里只说了 synthetic。
- **"假如"的配对种子**：两组的第 i 场用同一个随机种子，所以差别只来自那一处改动。
- 回放、定位球、赛前和阵容：Carry3 的稿子（#447）里有，这一版没放。
- **接真实比赛的路径**：写一个转换器就能接真实数据。

## 怎么做出来的

1. 配音：用 `edge-tts` 生成，微软神经语音 `en-GB-RyanNeural`，语速 +6%，一共 7 句。
2. 录制：`scripts/video/rec.mjs`。
   - 用无头 Chrome（1920×1080）打开线上网站，按写好的步骤移动鼠标、点击、滚动；
   - 通过开发者工具的屏幕录制逐帧存下来，再按真实时间合成 30 帧视频；
   - 画面里的鼠标指针是脚本画上去的。
3. 卡片：`scripts/video/cards.py` 生成结尾卡、标题卡和每段的小标签。
4. 剪辑：`scripts/video/edit.py` 用 ffmpeg 剪片段、叠配音和标签、烧字幕、统一音量，导出成片。

所有镜头都在 10-27 22:48–23:05（太平洋时间）录自线上网站，#446 部署之后。有几处故意没拍：
- ② ③ 两个转折点是自动摘要，没有打开；
- 关注球员后，Player spotlight 下面"In the turning points"里 ② 的标题拼错成 "Sahltessen"，这一块停在画面外；
- "假如"分析师版用的是页面上已经存好的结果，镜头里没有现场运行模拟。
